# Changelog

Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow [Semantic Versioning](https://semver.org/).

## [1.2.0] — 2026-11-24
### Added
- Synthetic example `examples/example-standard.pdf` (9 pages, free to redistribute), generated by `scripts/make-example.ts`, with its committed index. Use `make example` to rebuild them.
- Tests SR-060 (end-to-end analysis of the example, committed index up to date) and SR-061 (no other PDFs or indexes in the repository). `.gitignore` excludes third-party documents.

### Changed
- Analyzer r4: sequential bilingual standards stop before the French duplicate, IEC introduction numbering (`0.1`, `0.2`) is indexed, and early European annexes no longer prevent parsing the numbered standard body. IEC requirement/practice identifiers embedded in headings, such as `CR 1.1` and `SM-1`, remain searchable in their clause titles. Cached indexes from older analyzer revisions are rebuilt automatically.
- Analyzer r3: content of tables and figures is no longer read as part of a "shall" sentence (it used to merge figure labels into the next requirement and count requirement text quoted in table cells). Clauses, definitions, regions, tables and figures are unchanged. Cached indexes from r2 are rebuilt automatically.

## [1.1.0] — 2026-11-24
### Added
- Versioning: one version source in `package.json`, shown in the header, in the HTML `generator` meta tag, in every index (`generator`) and in every report footer. The build also writes a versioned copy, `dist/clause-lab-v<version>.html`.
- Index schema 2 with a `generator` block (`app`, `version`, `analyzer`). Schema 1 files are upgraded on load; files with a newer schema are refused.
- Analyzer revision (`ANALYZER_VERSION` = 2). A cached index from another revision is rebuilt automatically.
- `make version` and `make bump PART=…` targets. Tests SR-050..SR-052.

### Changed
- Naming is now neutral about publishers. Index format id `clause-index` (was publisher-prefixed), page title "Clause Lab — standard indexer", and the IndexedDB name `clause-lab` (the local index cache is rebuilt once). Test fixtures and docs use the placeholder designation `STD`.
- Designation detection uses a generic pattern (publisher acronym + number + year). Output on the reference document is identical to 1.0.0.

## [1.0.0] — 2026-11-24
### Added
- First release: import-mode analysis (clauses, definitions, annexes, tables, figures, "shall" statements, Redline/Final parts) and a continuous margin-cropped viewer with red regions that continue across pages. Basket with notes and gap status. HTML report export, PNG and text copy, index JSON import and export.
