# Clause Lab — Specification

App version: **1.2.0** · Index schema: **2** (`clause-index`) · Analyzer revision: **3**. See `CHANGELOG.md`.

Single-file HTML app for analysing PDFs of standard documents the user owns: clause and definition indexing, continuous margin-trimmed viewing with red region framing, and a basket exportable as a report for gap analysis and citation.

Encoding strategy: **Option A, Base64** (speed). The pdf.js worker is stored Base64 in a non-executable `<script type="application/octet-stream">` tag and hydrated to a Blob URL in `requestIdleCallback` (or on first PDF open). The app script is inlined as an IIFE.

## 1. User requirements

| ID | Requirement |
|----|-------------|
| UR-001 | Open a locally owned standard PDF; nothing leaves the browser. |
| UR-002 | Import mode: analyse the PDF and produce a JSON index of clauses, definitions, annexes, tables, figures and "shall" requirements. |
| UR-003 | View the PDF as one continuous scroll with unnecessary margins cut. |
| UR-004 | Selecting an index entry shows its region framed by a red rectangle, continuing across page breaks. |
| UR-005 | Collect clauses/definitions in a basket with notes and gap status. |
| UR-006 | Export the basket as a single report (HTML, printable to PDF) with text and/or images and citations. |
| UR-007 | Know which app version produced an index or a report, and keep earlier index files usable. |
| UR-008 | Try and verify the app with an example that can be freely redistributed; no third-party document is stored in the repository. |

## 3. Subsystem requirements

| ID | Requirement | Parent |
|----|-------------|--------|
| SSR-010 | `extractPage` converts pdf.js runs to top-left coordinates and drops rotated runs (side stamps). | SR-010 |
| SSR-011 | `buildLines` groups runs by baseline; joins small-caps splits ("R ISK" → "RISK"); keeps char→x segments. | SR-010 |
| SSR-012 | Noise = text (digits normalised) repeated on ≥20 % of pages, or repeated in the top/bottom 10 % band, or stamp glyph runs. | SR-021 |
| SSR-013 | `isSuccessor` accepts n+1 / n+2 at any level or a new first child. | SR-011 |
| SSR-014 | Pages with ≥5 dot-leader lines are treated as table of contents and skipped. | SR-011 |
| SSR-016 | `joinLines` de-hyphenates, keeps list items/NOTEs on new lines, removes spaces before punctuation. | SR-010 |
| SSR-017 | `shallSentences` splits at sentence ends (ignoring e.g./i.e.), keeps "[Class …]" markers, excludes NOTE/EXAMPLE blocks and table/figure content (analyzer r3). | SR-013 |
| SSR-015 | Designation = most frequent match of a generic pattern: publisher acronym(s) (2–6 capitals, `/`-joined), optional TR/TS, number with parts, optional year; amendments (`+AMDn:yyyy`) appended when frequent. | SR-032 |
| SSR-041 | SHA-256 via SubtleCrypto, FNV-1a fallback. | SR-040 |

## 5. Risk analysis and mitigations

| Req | Risk | Mitigation |
|-----|------|------------|
| SR-010 | Main-thread stall on 800-page standards. | Text extraction is async per page (pdf.js worker) with progress; analysis is linear; index cached by hash so it runs once. |
| SR-011 | Heading false positives (numbers in tables, "2015 …"). | Successor check, left-margin and font-size gates, numeric headings disabled inside annexes and after Bibliography. |
| SR-011 | Missed heading (layout variant) → previous clause region too long. | Successor tolerates one skipped number; user can re-run analysis; index JSON is editable. |
| SR-012 | Wrong region misleads a citation. | Red frame is always shown on the real page so the user verifies visually before adding to the basket; report includes the page image. |
| SR-013 | Table end heuristic includes trailing text. | Stops at the next heading/caption or two full-width body lines; image shows exactly what is cited. |
| SR-014 | Redline text (struck) indexed as normative. | Parts separated; Final selected by default. |
| SR-020 | Out of memory with many high-DPI canvases. | Only visible ±1 pages rendered; canvases beyond ±4 pages released; DPR capped at 2.5. |
| SR-031 | Large report (many images). | Images rendered on demand at export only; text-only option. |
| SR-040 | Storage unavailable (private mode, sandbox). | All storage calls wrapped; app works without persistence; index export/import as file. |
| SR-051 | Old index silently misread after a schema change. | Explicit schema number; migration function with tests; newer schemas refused. |
| SR-052 | Stale cached index after a detection fix gives wrong regions. | Analyzer revision stored per index; mismatch triggers re-indexing with a notice. |
| SR-060 | Example drifts from the analyzer, so docs and tests disagree. | Test compares the committed index with a fresh analysis; `make example` regenerates both. |
| SR-061 | A licensed document or an index carrying its text is committed by mistake. | `.gitignore` rules plus a unit test that fails if any other PDF or index is present. |
| UR-001 | Copyright: licensed PDF content distributed. | PDF never uploaded or embedded; index and reports stay local; no PDF bundled in the published app. |
